为统一公司前端开发标准，提升页面质量与开发效率，特制定本规范。
一、技术选型
1. 框架：Vue 3 + TypeScript，组件库使用 Element Plus。
2. 构建工具：Vite，包管理统一使用 npm。
3. 状态管理：Pinia；路由：Vue Router。
二、编码规范
1. 组件命名采用 PascalCase，文件名与组件名保持一致。
2. 样式优先使用 CSS 变量与设计令牌，禁止写死色值。
3. 接口请求统一封装，错误处理须给出用户可读提示。
4. 页面须适配 1920x1080 与 1366x768 两种主流分辨率。
三、提交与发布
1. 代码提交前须执行 lint 与单元测试。
2. 合并主分支须通过 Code Review。
3. 发布采用版本号语义化，重大变更须更新变更日志。
